# Section Rules

## A) HERO

**Goal:** Make the offer instantly clear and reduce the biggest objection early.

### Rules

- **Headline** must be descriptive: WHAT you sell + WHO it's for (+ OUTCOME if fits)
- **Subheadline** must include either:
  - How it works (mechanism/process), OR
  - Why believe it (proof/constraint)
- **Optional credibility line**: Only if trust is #1 blocker OR offer is novel/complex

### Do / Don't

```
DON'T: "Become an AI-first company."
DO: "AI automation for {ICP} that want {Outcome}."
```

## C) FEATURES / BENEFITS + OBJECTIONS

**Goal:** Make the promise concrete and handle objections using reality.

### Rules

- **Feature header** = blunt value prop (not a capability)
- **Feature paragraph** (max 2 sentences):
  - Sentence 1: concrete value + deliverable
  - Sentence 2: handle one objection + proof/constraint
- Tie each feature to hero outcome

### Do / Don't

```
DON'T header: "Powerful automation."
DO header: "Fewer manual follow-ups."

DON'T paragraph: "We leverage cutting-edge AI…"
DO paragraph: "We build {deliverable}. You get {outcome}. If {objection}, we {constraint/proof}."
```

---

## D) HOW IT WORKS / PROCESS

**Goal:** Reduce confusion and perceived effort.

### Rules

- 3–5 steps
- Write in two passes:
  - Pass 1: titles only (lock first)
  - Pass 2: subtitles (lock one at a time)
- **Step title**: Verb + Deliverable (max 6 words)
- **Step subtitle**: 1 sentence, max 14 words, must include time, output, or decision

### Do / Don't

```
DON'T: "We tailor solutions to your needs."
DO title: "Audit your workflow"
DO subtitle: "We map bottlenecks and pick 3 quick wins."
```

## F) FAQ

**Goal:** Remove last doubts in a human, helpful tone.

### Rules

- Questions must mirror intake objections
- Answers: 2–3 sentences, max 60 words
  - Sentence 1: direct answer (Yes/No/It depends)
  - Sentence 2: rationale/constraint/what happens next
  - Sentence 3 (optional): proof reference or `[TBD proof]`

---

## G) CTA SECTION

**Goal:** Make next step obvious and low-friction.

### Rules

- CTA headline restates outcome + who it's for
- Button matches intake CTA
- Microcopy reduces friction (only if true; else omit)

---

## H) FOOTER

**Goal:** Essentials only.

Keep minimal: copyright, links, contact.

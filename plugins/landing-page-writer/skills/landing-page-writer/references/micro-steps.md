# Micro-Steps by Section

## Workflow Per Micro-Step

1. Generate 10 strong options
2. Ask user to choose by ID
3. Confirm: "Locked: {ID}."
4. Move to next micro-step

---

## A) HERO Micro-Steps

```
H1) Headline options (10) → lock
H2) Subheadline options (10) → lock
H3) Optional credibility/objection line (10 OR "skip") → lock
H4) CTA button options (10) → lock
H5) Microcopy options (10) → lock
```

---

## B) SOCIAL PROOF Micro-Steps

```
SP1) Social proof line options (10 OR placeholder) → lock
```

---

## C) FEATURES Micro-Steps

```
F0) Propose feature themes (3–6) → user approves → lock

Then for each feature i (one at a time):
Fi1) Header options (10) → lock
Fi2) Paragraph options (10) → lock
Fi3) Proof/Visual placeholder (1 short line) → lock
```

---

## D) PROCESS Micro-Steps

```
P1) Step TITLES only — provide 10 full variants (3–5 titles each) → lock one variant

Then for each step:
P2) Step 1 subtitle options (10) → lock
P3) Step 2 subtitle options (10) → lock
P4) Step 3 subtitle options (10) → lock
... repeat until all subtitles locked

P_last) Optional closing line options (10): "What you get at the end" → lock
```

---

## E) PRICING Micro-Steps

```
PR1) Pricing line options (10 OR placeholder) → lock
PR2) Included bullets options (10 sets of 2–4 bullets) → lock
```

---

## F) FAQ Micro-Steps

```
FAQ0) Propose 5–8 questions based on intake objections → user approves → lock

Then per question (one at a time):
FAQ1) Q1 answer options (10) → lock
FAQ2) Q2 answer options (10) → lock
... repeat until all answers locked
```

---

## G) CTA SECTION Micro-Steps

```
CTA1) CTA headline options (10) → lock
CTA2) Button options (10) → lock
CTA3) Microcopy options (10) → lock
```

---

## H) FOOTER Micro-Steps

```
FT1) Footer line options (10) → lock
```

---

## Full Flow Example

For a typical service landing page:

```
1. H1 (headline)
2. H2 (subheadline)
3. H3 (credibility line or skip)
4. H4 (CTA button)
5. H5 (microcopy)
6. SP1 (social proof)
7. F0 (feature themes)
8. F1-1, F1-2, F1-3 (feature 1)
9. F2-1, F2-2, F2-3 (feature 2)
10. F3-1, F3-2, F3-3 (feature 3)
11. P1 (process titles)
12. P2, P3, P4 (process subtitles)
13. P_last (closing line)
14. FAQ0 (question list)
15. FAQ1, FAQ2, FAQ3... (answers)
16. CTA1, CTA2, CTA3
17. FT1 (footer)
18. FINAL ASSEMBLY
```

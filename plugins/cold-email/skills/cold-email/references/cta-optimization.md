# CTA Optimization

## Principles

- Soft > hard
- Specific > vague
- Low commitment > high commitment
- One CTA only

## CTA Upgrades

| Bad CTA | Good CTA |
|---------|----------|
| "Let me know if you're interested" | "Worth a quick chat?" |
| "Book a demo" | "Worth 15 min to see if there's fit?" |
| "Schedule a call" | "Open to a quick call this week?" |
| "Let's connect" | "Should I send more info, or not relevant?" |
| "Reply to this email" | "Worth exploring, or should I close the loop?" |

## High-Performing CTA Patterns

### Binary CTAs

```
Worth a chat, or off base?
```

```
Relevant, or should I leave you alone?
```

```
Open to this, or bad timing?
```

### Soft Question CTAs

```
Worth a quick chat?
```

```
Worth 15 minutes?
```

```
Make sense to connect?
```

### Permission CTAs

```
Mind if I send more details?
```

```
Should I share how we did it?
```

```
Want me to send a quick case study?
```

## CTA Selection by Goal

| Goal | Best CTA Style |
|------|----------------|
| Book meeting | "Worth 15 min this week?" |
| Get reply | "Worth exploring?" |
| Send resource | "Want me to send {{resource}}?" |
| Qualify interest | "Relevant, or off base?" |

## CTAs to Avoid

- Multiple options ("Tuesday or Thursday?")
- Calendly links in first email
- "Let me know your thoughts"
- "Looking forward to hearing from you"
- "Please advise"

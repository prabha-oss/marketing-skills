# Subject Lines

## Principles

- Under 6 words ideal
- No clickbait
- Lowercase often outperforms
- No spam trigger words (free, guarantee, act now)

## Subject Line Types

### Curiosity-Based

```
Quick question about {{company}}
```

```
{{Name}}, thought of you
```

```
Idea for {{company}}
```

```
Question about {{role/function}}
```

### Pain-Based

```
{{pain}} at {{company}}?
```

```
Struggling with {{problem}}?
```

```
{{outcome}} without {{pain}}
```

### Direct

```
15 min — {{outcome}}
```

```
{{Name}} ↔ {{Your name}}
```

```
For {{Name}}
```

### Personalized

```
Saw your {{trigger event}}
```

```
Re: {{their content/post}}
```

```
{{mutual connection}} suggested I reach out
```

### Follow-up

```
Re: {{original subject}}
```

```
Circling back
```

```
One more thing
```

```
Closing the loop
```

## Subject Lines to Avoid

- "Quick question" (overused)
- "Touching base" (meaningless)
- "Following up" (without context)
- ALL CAPS anything
- Excessive punctuation!!!
- Emojis (usually)

## Testing Approach

A/B test subject lines with:
- Same email body
- 50/50 split
- Measure open rate
- Winner becomes control

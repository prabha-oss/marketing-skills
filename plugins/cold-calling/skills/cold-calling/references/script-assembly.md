# Script Assembly

## Full Call Flow Structure

```
1. OPENER
   [Permission-based or pattern-interrupt opener]

2. REASON FOR CALL
   [One sentence: who you help + outcome]

3. DISCOVERY QUESTIONS
   [2-3 qualifying questions]

4. OBJECTION RESPONSES
   [Prepared responses for top 3 likely objections]

5. CTA
   [Single, low-friction next step]

6. FOLLOW-UP
   [If deferred: email template + callback timing]
```

## Example: SaaS Sales Tool

### Opener
```
"Hey {{Name}}, quick one — did I catch you at a bad time?"
```

### Reason for Call
```
"We help B2B sales teams book 30% more meetings without adding headcount. Wanted to see if outbound is a priority for you."
```

### Discovery Questions
```
1. "Are you doing outbound currently, or mostly inbound?"
2. "What's been the biggest challenge with booking meetings?"
3. "Is this something you're actively trying to solve?"
```

### Objection Responses
```
"Not interested" →
"Totally fair. Quick question — are you hitting your meeting targets, or is that a pain point?"

"Send an email" →
"Happy to. So I send something relevant — is outbound something you're focused on this quarter?"

"We have something" →
"Good to hear. Curious — are you seeing the results you want from it?"
```

### CTA
```
"Worth a 15-minute call to see if there's fit, or am I off base?"
```

### Follow-up (if deferred)
```
Email subject: "Quick follow-up"

{{Name}},

Good chatting earlier. As promised, here's a quick overview of how we help teams like {{company}} book more meetings.

[One-liner + link]

Worth continuing the conversation?

{{Signature}}
```

## Example: Agency Services

### Opener
```
"Hey {{Name}} — quick context so I don't waste your time."
```

### Reason for Call
```
"We work with agency owners stuck at 10-15 clients, helping them scale without adding headcount. Curious if growth is a focus for you right now."
```

### Discovery Questions
```
1. "Are you actively trying to grow, or more focused on retention?"
2. "What's been the biggest bottleneck to taking on more clients?"
3. "Is this something you'd want to solve in the next quarter?"
```

### CTA
```
"Would a 20-minute strategy call make sense, or is this not a priority?"
```

---

## Script Assembly Rules

1. **Keep it conversational** — Scripts are structure, not word-for-word
2. **Prepare for 3 objections** — The ones you hear most often
3. **Have one CTA ready** — Don't improvise
4. **Plan the follow-up** — Know what happens if they defer

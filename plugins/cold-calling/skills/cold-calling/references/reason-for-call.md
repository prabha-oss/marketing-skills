# Reason for Call

## Purpose

Answer "Why are you calling me, now?" in one sentence.

## Formula

```
"We help [specific role/company type] [achieve outcome] — I wanted to see if that's relevant for you."
```

## Examples

### SaaS / Tech

```
"We help B2B SaaS teams book 30% more demos without adding headcount — curious if outbound is a priority for you right now."
```

```
"We help product teams ship faster by automating QA — wanted to see if testing is a bottleneck for you."
```

### Agency / Services

```
"We work with agency owners who are stuck at 10-15 clients — helping them break through without hiring more salespeople."
```

```
"We help marketing agencies productize their services so they can scale without burning out — is that something you've thought about?"
```

### E-commerce

```
"We help e-commerce brands reduce ad spend while scaling revenue — wanted to see if paid acquisition is a pain point."
```

```
"We help DTC brands increase repeat purchases by 40% — curious if retention is something you're focused on."
```

### Local Services

```
"We help contractors fill their calendar without relying on referrals — is lead gen something you're working on?"
```

## Rules

- One sentence max
- Specific outcome, not features
- End with relevance check, not pitch
- Use numbers when possible
- Match language to their industry

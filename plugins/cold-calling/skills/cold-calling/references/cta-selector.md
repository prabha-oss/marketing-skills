# CTA Selection

## Principles

- Soft > hard
- Specific > vague
- Low commitment > high commitment
- One CTA only

## Selection Logic

| Situation | Best CTA |
|-----------|----------|
| High interest | "Let's book 15 minutes this week" |
| Lukewarm | "Worth a quick 10-minute call to see if there's fit?" |
| Resistant but engaged | "Can I send a one-pager and follow up Thursday?" |
| Senior exec | "15-minute sanity check — worth it or no?" |
| Deferred | "I'll follow up [day] — fair?" |

## CTA Templates

### Direct CTAs

```
"Let's book 15 minutes this week — what works?"
```

```
"Can we continue this Thursday at 2pm?"
```

### Soft CTAs

```
"Worth a quick chat, or am I barking up the wrong tree?"
```

```
"Should I close the loop, or leave you alone?"
```

```
"Open to this, or bad timing?"
```

### Binary CTAs (high-performing)

```
"Worth exploring, or off base?"
```

```
"Relevant, or should I leave you alone?"
```

```
"Worth 15 minutes, or not a fit?"
```

### Deferred CTAs

```
"I'll send a quick email and follow up Thursday — fair?"
```

```
"Let me send you one thing. If it's relevant, we'll talk. If not, no worries."
```

## Rules

- Never give multiple options
- Be specific about time/day when possible
- Make it easy to say yes
- Make it okay to say no

# Discovery Questions

## Purpose

Qualify fast without pitching. Max 3 questions on a cold call.

## Yes/No Qualifiers (use first)

```
"Are you currently doing any outbound?"
```

```
"Is [problem] something you're actively trying to solve?"
```

```
"Do you have someone handling [function] internally?"
```

```
"Is this something that's on your radar for this quarter?"
```

```
"Are you the right person to talk to about [function]?"
```

## Open-Ended Probes (use if qualified)

```
"What's your current approach to [problem]?"
```

```
"What's been the biggest challenge with [function]?"
```

```
"If you could fix one thing about [area], what would it be?"
```

```
"What's driving the interest in solving this now?"
```

```
"What have you tried so far?"
```

## Rules

- Max 3 questions on cold call
- Listen more than talk
- Mirror their language back
- Don't interrogate — have a conversation

## Question Selection by Stage

| Stage | Question Type |
|-------|---------------|
| Early (unqualified) | Yes/No qualifiers |
| Mid (showing interest) | Open-ended probes |
| Late (ready for CTA) | Commitment questions |

## Commitment Questions

```
"Would it make sense to continue this conversation?"
```

```
"Is this worth exploring further?"
```

```
"Should we schedule time to dig deeper?"
```

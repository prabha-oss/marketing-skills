# Landing Page Intake Questions

## Question Set (17 total, in order)

### Batch 1: Business Basics (Q0-Q3)

**Q0) Business type**
Is this a PRODUCT business or a SERVICE business?

**Q1) Product/service name?**

**Q2) Describe what you offer in detail.**
List the main features/deliverables.

**Q3) Who is it for?**
(industry + role + company type/size)

**Q4) What action should visitors take?**
- Book a call
- Request a quote
- Buy
- Sign up
- Download
- Other

---

### Batch 2: Trigger, Problems, Outcomes (Q5-Q8)

**Q5) What "trigger moment" makes them start looking?**
What happened right before they search?

**Q6) Top 3 problems they want solved**
(practical problems)

**Q7) What outcome do they get?**
(end result)

**Q8) How fast can they expect results?**
(typical timeframe)

---

### Batch 3: Differentiation and Proof (Q9-Q11)

**Q9) What have they already tried that didn't work?**

**Q10) Top 3 reasons they choose you**
(advantages / guarantees / specialization)

**Q11) What proof do you have?**
- Testimonials
- Case studies
- Numbers/metrics
- Portfolio
- Logos
- Certifications
- Press mentions

---

### Batch 4: Process, Objections, Boundaries (Q12-Q16)

**Q12) Do you have a clear process?**
If yes, list it in 3–5 steps.
If no, say "no clear process".

**Q13) Included vs not included**
(boundaries)

**Q14) Main friction/hesitation + top objections**
(list up to 3)

**Q15) Who is this NOT for?**
(bad fit)

**Q16) What do you need from the customer to succeed?**
(requirements: access, info, approvals, budget, etc.)

---

## Questioning Rules

- Ask max 4 questions per message
- Keep numbering visible (Q0, Q1, etc.)
- If vague answer → ONE follow-up forcing specificity
- Follow-ups count toward 17 total limit
- Prefer multiple-choice when possible
- Use plain language

## Flow Summary

```
Message 1: Q0-Q3 (with Q4)
Message 2: Q5-Q8
Message 3: Q9-Q11
Message 4: Q12-Q16
Message 5: Structure recommendation
Message 6: Confirmation request
Message 7: Final output
```
